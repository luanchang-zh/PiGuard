# 单元验证

P1 已覆盖 fake clock、六个场景、采样质量、距离映射和配置校验。P2 已覆盖遗嘱、2 Hz 遥测、重连 seq 和断连后继续采样。P3 已覆盖四条规则的持续时间、恢复滞回、模拟输出和事件缓存。P4 已覆盖四种命令的有效期、去重、重启不确定结果和模拟输出仲裁。报告见 [P1](../../../docs/verification/unit/p1-local-data-chain.md)、[P2](../../../docs/verification/unit/p2-uplink.md)、[P3](../../../docs/verification/unit/p3-local-warnings.md) 与 [P4](../../../docs/verification/unit/p4-commands.md)。使用临时数据库，不需要 GPIO 或网络。
